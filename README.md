# La Forja del Artesano 🛠️

Página web de ventas de pulseras artesanales con integración directa a WhatsApp.

## Características ✨

- **Configurador de Pulseras**: Selecciona estilo, material y color
- **Cálculo Dinámico de Precios**: Actualización en tiempo real
- **Opciones de Entrega**: Punto de encuentro o envío a domicilio
- **Integración WhatsApp**: Envío automático de pedidos
- **Diseño Responsivo**: Optimizado para móvil y desktop
- **Interfaz Temática**: Diseño tipo "misión/quest" con estilo oscuro

## Opciones Disponibles

### Estilos de Pulseras
- Nudo Cobra ($1.00)
- Aleta de Tiburón ($1.50)

### Materiales
- Paracord (Verde Militar)
- Cáñamo (Rosado, Blanco, Negro, Verde)

### Métodos de Entrega
- Punto de encuentro (Gratis)
- Envío a domicilio (+$5.00)

## Cómo Usar

1. Abre `index.html` en tu navegador
2. Configura tu pulsera:
   - Elige el estilo
   - Selecciona el material y color
   - Elige método de entrega
3. Completa tus datos (nombre, teléfono, ubicación)
4. Haz clic en "Enviar Pedido al Artesano"
5. Se abrirá WhatsApp con tu pedido listo para enviar

## Personalización

Puedes editar fácilmente:
- Colores y diseño en la sección `<style>`
- Precios en las tarjetas de selección
- Número de WhatsApp en la función `enviarPedido()`
- Mensajes y textos del formulario
